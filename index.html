What the System Can Do

Real-time computer vision and AI integration brings surgical safety to a new level.

🎯

Tool Detection (YOLOv8)

The YOLOv8 model detects 16 different surgical instruments in real time from the live camera feed with 95%+ accuracy and marks them with colored bounding boxes.

✋

Hand Tracking (MediaPipe)

Simultaneous tracking of up to 4 hands via MediaPipe Hand Landmarker. Determines whether a tool is in-hand or on the table using an IoU overlap score.

⏱

Usage Time Measurement

Records the in-hand duration of each tool frame by frame. Displays how many times it was picked up and the total usage time.

🚨

Missing Tool Alert

Counts tools present at surgery start; provides an audio and visual red alert for any tool missing at the end of the procedure.

🤖

AI Surgical Report

DeepSeek-R1 automatically analyses all tool usage data every 15 seconds and generates a concise, professional assessment for the surgeon.

📄

CSV, PDF & Excel Export

At the end of the session all events, tool durations and AI reports are automatically saved as CSV, PDF and Excel (.xlsx) files.
